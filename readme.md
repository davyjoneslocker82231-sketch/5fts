i suggest 130/128 BPM cus they sound more like deadmau5. and it's simple
use 7 or 7sus4 (somewhere along the 7 chord progression) to get that pure chord feel. 
also, use the preset "chords of life" in z3ta. you'll see why.
Maj7 and continuing until the last chord with 7 in it is actually good for deadmau5 chord progressions.
The chords I use are D#maj7, and i pitch it up 6 notes, then 2 notes down, then another 2 notes down. I think it's 3 notes down. Idk.
So then the chord progression is D#maj7, Amaj7, Gmaj7, Fmaj7 (or Emaj7). You should also repeat it 4 times by each note so then it's like...
Do-do-do-do (D#maj7) DO-DO-DO-DO (Amaj7) Do-Do-Do-Do (Gmaj7) do-do-do-do (Fmaj7/Emaj7). Sorry if that was stupid.
You also can do this chord thing where it catches you off guard. 
So, we can edit it to be holding the note, not a 4 bar. Let's hold it for 8/16 bars. 
Now the catch off guard part is when we change it from the note when you least expect it.
(key= each o represents a bar)
So it's Dooo- (D#maj7) DOOO- (Amaj7) Dooo- (Gmaj7) dooo- (Fmaj7/Emaj7). You expect it to be 4 bars each, but it catches you, and that's why it makes it so interesting.
You can also intertwine it, so it stays "technically" 4 bars but it feels like 3 bars. 
So again, we gotta do the "do" thing.
Doooo (D#maj7 but Amaj7 on the last "o") DOOOO (Amaj7 but Gmaj7 on the last "o") Doooo (Gmaj7 but Fmaj7/Emaj7 on the last "o") doooo (then just Fmaj7/Emaj7 playing)
Then you change the delay on the synth while the song is playing, also layer your drums and make sure you check it's volume.
Also, if you don't like delay on ASDR, change the volume on z3ta+ 1 by a automation clip. The reverb changes on how much volume there is.
Now you get to the arp part. DO NOT USE ARP PRESETS. AT ALL. Use the arpeggiator. Get your chords, then arpeggiate it.
I suggest 3xOsc for arps. No presets, btw.
3xOsc also has Mod X / Y features so its also flexible..
